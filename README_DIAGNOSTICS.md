# 平衡车 DMP 调试版

从 `F1_balance_DMP_FIFO` 复制。姿态计算、电机控制、PID 默认参数、保护逻辑和 UART 选择保持副本创建时的设置；只扩展 VOFA 输出并降低 RUNNING 期间的诊断文本频率。

该副本默认串口为 UART2，波特率 9600。每约 100 ms 发送一行 `:` 开头的 11 个浮点数，VOFA 通道顺序：

| 通道 | 内容 | 单位 |
|---|---|---|
| I0 | DMP X 轴角度 | 度 |
| I1 | 原始陀螺仪经零偏校准后的角速度 | 度/秒 |
| I2 | 左侧编码器增量 | 计数/5ms |
| I3 | 右侧编码器增量 | 计数/5ms |
| I4 | 滤波后平均轮速 | 计数/5ms |
| I5 | 直立环输出，经过 ±PWM_MAX 限幅 | PWM 计数 |
| I6 | 位置环给出的目标速度 | 计数/5ms |
| I7 | 速度环输出的角度修正量，已限幅 | 度 |
| I8 | 速度环积分贡献 | 度 |
| I9 | 直立环 P 分量：Kp × (目标角度 - 当前角度) | PWM 计数 |
| I10 | 直立环 D 分量：-Kd × 角速度 | PWM 计数 |

I9+I10 是直立环限幅前的值；达到限幅后不一定等于 I5。I5 也不是电机端最终占空比，电机驱动还有死区补偿、转向量和限幅。I6～I10 用于 RUNNING 状态诊断；校准或 READY 阶段不能当作运行中的控制输出。

RUNNING 时详细文本改为约 5 秒一次；其他状态仍约 1 秒一次。由于 UART2 只有 9600 波特，串口队列繁忙时可能丢帧；不能把缺失数据当作测量结果。上报频率只是 10 Hz，不能测出几毫秒的瞬态或 DMP 确切延迟；额外格式化也会增加 CPU 工作量。如果出现 FAULT 3，不要继续实车测试，改回原版并记录现象。

建议先停止车，复位或重新启动车使位置参考回到当前点，待稳定后记录几秒，再从轻推开始；人应能及时扶住车，看到持续加速或将要倾倒立即停机。记录原始串口文本（含每五秒 DBG/POS 行）并回传。不要先改变现有参数，测试结束确认后再讨论调参。

Keil 打开 `MDK-ARM/F1_balance_DMP.uvprojx`；CLion 打开项目根目录。自行检查当前车上的 PID 实际参数，串口调参只保存于 RAM，复位会恢复此副本的默认值。
