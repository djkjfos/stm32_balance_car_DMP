# STM32F103C8T6 平衡车工程使用说明

## 位置保持（编码器）

运行时累加两轮平均编码器增量，位置 P 环把相对位移转换为速度环目标。默认位置增益 0.005，返回速度限制为 ±2 计数/5ms；这些是需要实车调节的初始值，不保证所有底盘稳定。启用或倾倒恢复时以当前位置为零点；`ASP` 非零时按原有目标速度行驶并重设零点，变回零后保持当时位置。停机、重新启动或校准会重置零点。编码器打滑、转弯和倾倒会使估计位置偏离真实位置，这不是绝对定位。

串口命令 `PKP 0.005` 设置位置比例增益（范围 0～0.1，设 0 关闭位置修正）；`PLIM 2` 设置位置环返回速度上限（范围 0～20 计数/5ms）。参数只在 RAM 中生效，复位恢复默认值。`STAT 0` 和定期诊断中的 `POS` 是相对位移，`VPS` 是送给速度环的目标速度，`PKP` 和 `PLIM` 分别为增益及速度限幅。

上车前必须验证两轮编码器的前进符号一致，并先确认原有直立环和速度环稳定；应扶住车辆、先用小扰动测试。此工程上电校准后可能自动启动电机。

本次按 STM32F103C8T6、LQFP48 和现有 TB6612 类驱动接口修改，使用 STM32CubeMX 6.6.1、STM32Cube FW_F1 V1.8.7、Keil ARM Compiler 5。没有向开发板烧录。

## 接线

下列 PA/PB/PC 是芯片 GPIO 名称，不是封装脚序号。

| 功能 | STM32 引脚 |
|---|---|
| 电机 A PWMA | PB6，TIM4_CH1 |
| 电机 A AIN1 / AIN2 | PB12 / PB13 |
| 电机 B PWMB | PB7，TIM4_CH2 |
| 电机 B BIN1 / BIN2 | PB14 / PB15 |
| 驱动 STBY | PB0；PB5 现在用于屏幕 SPI1 MOSI |
| 编码器 A 的 A/B 相 | PA0 / PA1，TIM2 |
| 编码器 B 的 A/B 相 | PA6 / PA7，TIM3 |
| MPU6050 SCL / SDA | PB10 / PB11，I2C2，100kHz |
| MPU6050 地址 | 7 位地址 0x68，AD0 应为低电平 |
| MPU6050 INT | PC14，预留普通输入；本版本使用定时读取，不启用数据就绪中断 |
| I2C1 扩展 SCL / SDA | PB8 / PB9，100kHz；已初始化，当前无应用读写任务 |
| ST7789 SPI 时钟 / 数据 | PB3 / PB5，SPI1 重映射，18MHz，DMA1 Channel3 |
| ST7789 CS / DC / RES | PA5 / PA8 / PA15，普通 GPIO 输出 |
| 调参串口 TX / RX | PA9 / PA10，USART1，115200、8N1 |
| 龙芯通信预留 TX / RX | PA2 / PA3，USART2，115200、8N1；已初始化，未定义通信协议 |
| 电池分压检测预留 | PA4，ADC1_IN4；已初始化和校准，未假设分压比例或实现电量换算 |
| 启停按键 | PB1，上拉输入，按下接 GND；30ms 消抖，按一次启动、再按一次停止，长按只触发一次 |
| 其余引脚 | 接线前以 `I2C.ioc` 核对；PB4 没有配置成 SPI MISO |
| 状态灯 | PC13；本版本按常见低电平点亮的 LED 接法处理 |
| 下载与调试 | PA13 / PA14，SWD |

当前新增的是 SPI ST7789 屏幕，不能接到 I2C1/I2C2 当作 I2C 显示屏。旧 OLED 源码仍未加入 Keil 构建。屏幕初始化和刷新均由非阻塞状态机及 DMA 推进，控制模块的启停、防倒、校准代码保持原样。

电机驱动的逻辑电源按模块要求连接，电机电源使用与电机匹配的电源，各模块共地。串口 TX 接对方 RX。I2C 需要上拉到 3.3V，先核对传感器模块自带上拉；PA4 只能接分压后的 ADC 输入电压。

## 定时器和时钟

- 外部晶振按现有工程的 8MHz 配置，系统时钟 72MHz。
- TIM1：PSC=7199，ARR=49，5ms 更新节拍，200Hz。
- TIM2/TIM3：AB 相正交编码器，TI12，16 位计数器，输入滤波器 6。
- TIM4：PSC=0，ARR=3599，两路 20kHz PWM，限幅 0～3599。
- ADC1：APB2 六分频，ADC 时钟 12MHz。
- SysTick 仅提供 HAL 毫秒时基；I2C 和控制计算均在主循环中执行。

TIM1 中断只提交节拍。运行时主循环若积压两个节拍，立即拉低 STBY 并锁定超时故障，避免阻塞时维持旧电机输出。

## 启动与串口命令

每条命令以换行 `\n` 或 `\r\n` 结束。初始化与校准期间保持电机关闭，MPU6050/MPU6500 初始化成功后，扶正并保持静止约 1 秒完成校准。姿态沿用原工程 `atan2(ay,az)` 绕 X 轴的定义：车体直立时应接近 0 度；若传感器安装方向不同，应先调整轴映射。

上电校准收集 200 个有效样本（200Hz 下约 1 秒），对 X 角度、三轴角速度、三轴加速度分别计算均值及标准差，并比较前后各半秒的均值漂移；普通噪声或孤立小毛刺不再凭一次峰峰值超限就清零。角度标准差上限 1°，各轴角速度标准差上限 2°/秒，加速度标准差上限 0.03g；前后半窗漂移上限分别为 0.5°、1°/秒、0.025g。实际移动、明显抖动、采样间断、轮动或原始量超范围仍会拒绝校准，不通过时重新收集一整段样本。

校准诊断 `LAST` 给出最近一次重置原因：SAMPLE_GAP（采样间断）、ANGLE_RANGE/GYRO_RANGE/GRAVITY_RANGE（原始量越界）、WHEEL_MOVED（轮动）、ANGLE/GYRO/ACCEL_NOISE（波动过大）、ANGLE/GYRO/ACCEL_DRIFT（姿态持续变化）。`CAL WINDOW` 显示最近完整窗口的标准差 SD 和前后半窗均值之差 DRIFT，角度单位为度、角速度为度/秒、加速度为 g。

上电或复位后的初始控制意图为启动：传感器初始化、连续静止校准成功后，若 PB1 已松开，程序自动进入 RUNNING，无需发送 ARM 1，也无需先按一次键。初始化和校准期间电机保持关闭。

PB1 按下为低电平，松开为高电平；运行后按一下停止，再按一下启动，30ms 消抖，长按不会反复切换。校准期间按一次键可取消本次上电自动启动；校准完成时按键仍按住，也会取消本次自动启动，之后需松开再重新按下。按键或串口停止后不会自行再启动。

校准未完成、姿态偏差过大或故障锁定时，按键不会启动；处理条件后松开再重新按下。仅倾倒保护允许扶正后自动恢复；传感器、超时、硬件故障仍锁定。显式 CAL 1 后只进入 READY，不自动重新启动。串口 `ARM 1/0` 保留作为可选调试接口，正常按键启停不需要发送串口命令。

| 命令示例 | 用途 |
|---|---|
| `STAT 0` | 查看状态、故障码和直立环增益 |
| `ARM 1` | 在已校准、姿态接近直立、数据新鲜且按键松开时启用闭环 |
| `ARM 0` | 关闭电机输出；清空控制积分及速度、转向目标 |
| `CAL 1` | 关闭输出、重新初始化 IMU 并重新校准；校准后按 PB1 或发送 ARM 1 启动 |
| `DKP 60` | 直立环 Kp |
| `DKD 0` | 直立环 Kd |
| `VKP 0` | 速度环 Kp |
| `VKI 0` | 速度环 Ki |
| `TKP 0` | 两轮速度差控制 Kp |
| `MDB 0` | 电机死区补偿，范围 0～3599 |
| `ASP 0` | 目标平均轮速，单位为每 5ms 编码器计数 |
| `TAG 0` | 目标两轮速度差，单位为每 5ms 编码器计数；不是偏航角 |

复位后若 DBG 显示 RUNNING、FAULT=0、STBY=1，表示已经启用闭环。PWM 为 0 不等于未启动：当前默认直立 Kp=60、Kd=0，接近校准零点时控制量很小，绝对值不超过 15 计数的电机命令会输出 0。串口设置的增益不持久保存，复位后恢复源码默认值。

参数限制：DKP/DKD/TKP 绝对值不超过 2000，VKP/VKI 不超过 20，ASP/TAG 不超过 500。非法数字、非有限值、超长帧和溢出帧不执行。串口调参不写入 Flash，复位后恢复源码默认值。

当前默认增益沿用原工程：直立 Kp=60、Kd=0，速度与转向增益为 0；这是待调试的初始值，未通过实车平衡验证。20kHz PWM 下的死区尚未测量，因此默认补偿为 0，不能沿用旧的 650 计数并假定有效。速度 Ki 沿用“每 5ms 采样”的离散增益定义。

## 状态、故障和数据

状态编号：0=校准中，1=就绪且电机关闭，2=闭环运行，3=故障且电机关闭。

故障编号：0=无，1=MPU6050 通信或数据异常，2=X 轴显示角度绝对值或相对校准零点的偏差任一达到 45 度，3=控制任务积压超时，4=电机/编码器硬件初始化失败。

倾倒、传感器异常和超时会将两路 PWM 清零并拉低 STBY，包括转向分量。45 度包含正负两个方向；防倒依据控制使用的滤波后 X 轴角度，不是对电池供电断电。

仅倾倒（FAULT=2）时继续读取姿态，保留之前的运行意图：显示角度、加速度角度及其相对零点偏差均回到正负 10 度以内，角速度小于 20 度/秒、重力幅值合理、轮子不转、按键松开，且连续 40 个有效采样周期（约 200ms），自动恢复 RUNNING。恢复使用原校准零点，无需重新校准；姿态滤波达到恢复范围所需时间另计。若中间重新倾斜、轮动或丢采样，200ms 连续窗口重新计数。倾倒时速度和转向目标清零。

倾倒等待期间按 PB1 或发送 ARM 0 会取消自动恢复、进入 READY；扶正后按 PB1 才重新启动。普通手动停止也不会因扶正自行启动。传感器、超时和硬件故障保持锁定；排除传感器或超时问题后可使用 CAL 1，再按 PB1。硬件初始化故障需要排查后复位，不能通过校准绕过。

串口每 100ms 输出六项数据：角度（度）、X 轴角速度（度/秒）、A 轮计数、B 轮计数、平均速度滤波值、直立控制输出。发送使用中断队列，不逐字节阻塞控制任务。

## 实车需要确认的方向

- `Core/user/encoder.h`：默认 ENCODER_A_SIGN=+1、ENCODER_B_SIGN=-1。向前推车时，两轮速度都应为正；不一致就修改对应符号。
- `Core/user/motor.h`：MOTOR_A_SIGN/MOTOR_B_SIGN 默认均为 +1，取决于电机接线。两轮“正输出”应对应同一车体前进方向。
- 安装轴方向、机械零点、驱动型号、电机/编码器极性和 PID 增益无法仅凭源码确定，本次没有实车验证。
